[.lead]
hwaccel.reset events are reported when a hardware accelerator is reset using software, and corrective actions typically involve following the documented corrective action guidance.

== hwaccel.reset
*Severity*::
NOTICE
*Description*::
This message occurs when a hardware accelerator is reset using software.
*Corrective Action*::
(None).
*Syslog Message*::
Hardware accelerator %s reset by %s.
*Parameters*::
*devName* (STRING): Name of the acceleration device; for example, "qat0".
*module* (STRING): Name of the software module or driver.
