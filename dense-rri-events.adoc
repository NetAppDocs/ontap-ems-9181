== dense.rri.wait.for.free.file.timedout
*Severity*::
ERROR
*Description*::
This message occurs when WAFL message corresponding to volume level dedupe or cross volume dedupe is timed out while waiting for the Remote Refcount Increment on volume.
*Corrective Action*::
(None).
*Syslog Message*::
Message is timed out while waiting for the Remote Refcount Increment on volume "%s".
*Parameters*::
*vol* (STRING): Volume name.
*msg* (STRING): WAFL Message name
