= fmmb.inststat events
:toc: macro
:toclevels: 1
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
fmmb.inststat events are reported when this message occurs whenever the mailbox instance state changes, and corrective actions typically involve following the documented corrective action guidance.

== fmmb.instStat.change
*Severity*::
INFORMATIONAL
*Description*::
This message occurs whenever the mailbox instance state changes.
*Corrective Action*::
(None).
*Syslog Message*::
%s on %s side.
*Parameters*::
*buff* (STRING): Instance state string.
*host* (STRING): Host string, which is either local or partner.
