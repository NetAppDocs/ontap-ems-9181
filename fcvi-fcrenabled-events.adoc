[.lead]
fcvi.fcrenabled events are reported when this message occurs if Fiber Channel Routing (FCR) functionality is enabled on the system, and corrective actions typically involve following the documented corrective action guidance.

== fcvi.fcrEnabled
*Severity*::
NOTICE
*Description*::
This message occurs if Fiber Channel Routing (FCR) functionality is enabled on the system.
*Corrective Action*::
(None).
*Syslog Message*::
FC-VI adapter: Fiber Channel Routing (FCR) is enabled.
*Parameters*::
(None).
