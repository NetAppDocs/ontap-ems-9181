== rri.aggr.nospace
*Severity*::
ERROR
*Description*::
This event is issued to indicate there is not enough free space to do RRI work.
*Corrective Action*::
Free disk space in the flexaggr, or increse the size of flexaggr, then retry the RRI operation.
*Syslog Message*::
[%s] : RRI on flexaggr %s has aborted because there is insufficient free space.
*Parameters*::
*oper* (STRING): RRI operation that is doing space check.
*flexaggr* (STRING): Name of Flexaggr.
