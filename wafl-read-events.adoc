= wafl.read events
:toc: macro
:toclevels: 1
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
wafl.read events are reported when potential incorrect data read is detected, and corrective actions typically involve following the documented corrective action guidance.

== wafl.read.incorrect.data
*Severity*::
NOTICE
*Description*::
Potential incorrect data read is detected.
*Corrective Action*::
(None).
*Syslog Message*::
Potential incorrect data read is detected in fsid 0x%08x
*Parameters*::
*fsid* (INT): File system identifier of the volume.
