= mpt.tmf events
:toc: macro
:toclevels: 1
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
mpt.tmf events are reported when the system cannot allocate a SCSI Task Management Function (TMF) request in the message processing technology (MPT)adapter driver, and corrective actions typically involve following the documented corrective action guidance.

== mpt.tmf.req
*Severity*::
NOTICE
*Description*::
This message occurs when the system cannot allocate a SCSI Task Management Function (TMF) request in the message processing technology (MPT)adapter driver.
*Corrective Action*::
(None).
*Syslog Message*::
Unable to allocate dedicated TMF request for device %s.
*Parameters*::
*mpt* (STRING): MPT device name.
