[.lead]
vfiler.unable events are reported when this message occurs during vFiler(tm) unit discovery, if one of the vFiler(tm) unit module initialization functions fails, and corrective actions typically involve following the documented corrective action guidance.

== vFiler.unable.initModules
*Severity*::
ERROR
*Description*::
This message occurs during vFiler(tm) unit discovery, if one of the vFiler(tm) unit module initialization functions fails.
*Corrective Action*::
(None).
*Syslog Message*::
Could not initialize modules for vFiler unit "%s".
*Parameters*::
*vfName* (STRING): The vFiler unit on the source.
