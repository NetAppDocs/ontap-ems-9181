Learn about de.pod EMS events, which report when a Kubernetes pod in AI Data Engine (AIDE) enters CrashLoopBackOff state.

== de.pod.crashloopbackoff
*Severity*::
ERROR
*Description*::
This message occurs when a Kubernetes pod in AI Data Engine (AIDE) enters CrashLoopBackOff state.
*Corrective Action*::
Contact NetApp technical support.
*Syslog Message*::
Pod %s in CrashLoopBackOff state. Container: %s, Restart Count: %s, Service: %s.
*Parameters*::
*podName* (STRING): Name of the pod.
*containerName* (STRING): Name of the container within the pod in CrashLoopBackOff state.
*restartCount* (STRING): Number of times the pod has restarted.
*serviceName* (STRING): Name of the impacted service.
*createTime* (STRING): Event creation time.
