[.lead]
volcmd.snapmirror events are reported when this mesage occurs to advise you that the 'vol snapmirror' set of commands has been removed, and corrective actions typically involve following the documented corrective action guidance.

== volcmd.snapmirror.removed
*Severity*::
ERROR
*Description*::
This mesage occurs to advise you that the 'vol snapmirror' set of commands has been removed.
*Corrective Action*::
Use the 'snapmirror' command instead.
*Syslog Message*::
The 'vol snapmirror' set of commands has been removed; use the 'snapmirror' command instead.
*Parameters*::
(None).
