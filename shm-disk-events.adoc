[.lead]
shm.disk events are reported when the system detects a lost write error, and corrective actions typically involve following the documented corrective action guidance.

== shm.disk.lostWriteError
*Severity*::
ERROR
*Description*::
This message occurs when the system detects a lost write error.
*Corrective Action*::
(None).
*Syslog Message*::
shm: Disk %s has detected and recovered from a lost write error; the system will fail the disk if possible.
*Parameters*::
*diskName* (STRING): Name of the disk.
