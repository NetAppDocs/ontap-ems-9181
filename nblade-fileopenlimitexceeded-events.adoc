nblade.fileopenlimitexceeded events are reported when the number of open files on a single SMB connection or session exceeds the system limit, and corrective actions typically involve following the documented corrective action guidance.

== Nblade.fileOpenLimitExceeded
*Severity*::
NOTICE
*Description*::
This message occurs when the number of open files on a single SMB connection or session exceeds the system limit.
*Corrective Action*::
(None).
*Syslog Message*::
Number of open files has reached the maximum limit of (%d).
*Parameters*::
*filesopen* (INT): Number of files that are open.
