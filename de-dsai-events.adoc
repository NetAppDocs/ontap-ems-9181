Learn about de.dsai EMS events, which report when there is an error starting up Data Services for AI.

== de.dsai.service.startup.fail
*Severity*::
ERROR
*Description*::
This message occurs when there is an error starting up Data Services for AI. In this state, some or all of the functionality related to classification and guardrails is impacted. However, the basic AI Data Engine functionality continues to work normally.
*Corrective Action*::
Contact NetApp technical support.
*Syslog Message*::
Failed to start Data Services.
*Parameters*::
(None).
