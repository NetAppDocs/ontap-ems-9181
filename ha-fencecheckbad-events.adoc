ha.fencecheckbad events are reported when the check for local fence returns a bad status, in the failover monitor during boot, and corrective actions typically involve following the documented corrective action guidance.

== ha.fenceCheckBad
*Severity*::
NOTICE
*Description*::
This message occurs when the check for local fence returns a bad status, in the failover monitor during boot. The system attempts to recover from this condition on its own.
*Corrective Action*::
(None).
*Syslog Message*::
The failover monitor fence check on this node returned an error status: %s
*Parameters*::
*status_str* (STRING): Status string for fence check.
