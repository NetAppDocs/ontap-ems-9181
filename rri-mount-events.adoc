[.lead]
rri.mount EMS events occur when to indicate that flexaggr RRI mount failed.

== rri.mount.fail
*Severity*::
NOTICE
*Description*::
This event is issued to indicate that flexaggr RRI mount failed.
*Corrective Action*::
(None).
*Syslog Message*::
RRI mount on flexaggr %s has aborted because of error %s.
*Parameters*::
*flexaggr* (STRING): Name of Flexaggr.
*err* (STRING): Error message that caused the failure.
