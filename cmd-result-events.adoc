= cmd.result events
:toc: macro
:toclevels: 1

:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
cmd.result events are reported when the system reboots as a consequence of executing the specified command, and corrective actions typically involve following the documented corrective action guidance.

== cmd.result.reboot
*Severity*::
NOTICE
*Description*::
This message occurs when the system reboots as a consequence of executing the specified command.
*Corrective Action*::
(None).
*Syslog Message*::
System rebooted for ('%s').
*Parameters*::
*cmd* (STRING): Command for which the system rebooted.
