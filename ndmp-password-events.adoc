= ndmp.password events
:toc: macro
:toclevels: 1
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
ndmp.password events are reported when this message occurs on NDMP service startup, when the password for the NDMP user account is still the default password, and corrective actions typically involve following the documented corrective action guidance.

== ndmp.password.warning
*Severity*::
ERROR
*Description*::
This message occurs on NDMP service startup, when the password for the NDMP user account is still the default password.
*Corrective Action*::
Use the 'ndmpd password' command to change the default password.
*Syslog Message*::
The NDMP user account has the default password set. Use the 'ndmp password' command to change the default password.
*Parameters*::
(None).
