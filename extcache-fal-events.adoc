[.lead]
extcache.fal events are reported when the external cache is informed that the Flash Adaptation Layer (FAL) has been taken offline, and corrective actions typically involve following the documented corrective action guidance.

== extCache.fal.offline
*Severity*::
NOTICE
*Description*::
This message occurs when the external cache is informed that the Flash Adaptation Layer (FAL) has been taken offline. As a result, caching operations that rely on the external cache might be suspended, which may impact system performance.
*Corrective Action*::
(None).
*Syslog Message*::
external cache has been informed that FAL has been taken offline.
*Parameters*::
(None).
