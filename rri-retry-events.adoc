= rri.retry events
:toc: macro
:toclevels: 1
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
rri.retry events are reported when this event is issued to indicate that flexaggr RRI inode has been requeued back to the queue in event of any failure, and corrective actions typically involve following the documented corrective action guidance.

== rri.retry.inode
*Severity*::
ERROR
*Description*::
This event is issued to indicate that flexaggr RRI inode has been requeued back to the queue in event of any failure.
*Corrective Action*::
(None).
*Syslog Message*::
RRI operation will be retried on flexaggr %s.
*Parameters*::
*flexaggr* (STRING): Name of Flexaggr.
